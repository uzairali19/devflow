# Principles — {{PROJECT_NAME}}

The rules this project follows when decisions get hard. Few and sharp —
three real principles beat ten aspirations. Examples to replace:

1. **Boring by default.** New tech needs an ADR proving the boring option fails.
2. **Everything observable.** If it can break, it logs and it's measurable.
3. **Markdown beside the code.** Decisions live in the repo, not in chat history.
